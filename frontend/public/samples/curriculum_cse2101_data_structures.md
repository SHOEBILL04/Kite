# CSE 2101: Data Structures and Algorithms I

- **Week 1:** Introduction to data structures, abstract data types (ADTs), and asymptotic complexity analysis (Big-O notation, Omega, Theta bounds).
- **Week 2:** Arrays, dynamic arrays, and memory allocation strategies.
- **Week 3:** Singly and doubly linked lists, pointer manipulation, and list traversals.
- **Week 4:** Stacks, call stack representation, and expression evaluation (infix to postfix).
- **Week 5:** Queues, circular buffers, and double-ended queues (deques).
- **Week 6:** Recursion and the call stack, divide and conquer principles.
- **Week 7:** Sorting algorithms: Insertion Sort, Selection Sort, and Bubble Sort.
- **Week 8:** Advanced sorting: Merge Sort, Quick Sort, and partition strategies.
- **Week 9:** Binary Trees, node representation, and recursive tree traversals (pre-order, in-order, post-order).
- **Week 10:** Binary Search Trees (BST), search, insertion, and deletion algorithms.
- **Week 11:** Hashing, hash functions, collision resolution via open addressing and separate chaining.
- **Week 12:** Graph representations: Adjacency Matrix and Adjacency List implementations.
