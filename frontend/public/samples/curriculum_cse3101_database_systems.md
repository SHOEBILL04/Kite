# CSE 3101: Database Management Systems

- **Week 1:** Introduction to Database Systems, File Systems vs DBMS, Data Models, and Three-Schema Architecture.
- **Week 2:** Entity-Relationship (ER) Modeling, Entities, Attributes, Relationships, Weak Entities, and Extended ER (EER) diagrams.
- **Week 3:** Relational Data Model, Relational Algebra operations (Select, Project, Rename, Union, Difference, Cartesian Product, Join).
- **Week 4:** Structured Query Language (SQL) I: DDL, DML, Basic Queries, Aggregation, and GROUP BY clauses.
- **Week 5:** SQL II: Complex Queries, Subqueries, Joins (Inner, Outer, Cross), Views, and Integrity Constraints.
- **Week 6:** Relational Database Design & Normalization: Functional Dependencies, Closure, and 1NF, 2NF, 3NF.
- **Week 7:** Advanced Normalization: Boyce-Codd Normal Form (BCNF), 4NF, Multi-valued Dependencies, and Lossless Joins.
- **Week 8:** Physical Storage & Indexing: Disk Storage, File Organization, Primary and Secondary B-Trees and B+ Trees.
- **Week 9:** Hashing techniques in databases: Static Hashing, Dynamic Hashing, and Hash Indexes.
- **Week 10:** Query Processing & Optimization: Query Execution Plans, Cost Estimation, Relational Algebra Equivalence Rules.
- **Week 11:** Transaction Management & ACID Properties: Serializability, Concurrency Control, Two-Phase Locking (2PL), Deadlocks.
- **Week 12:** Database Recovery Techniques: Write-Ahead Logging (WAL), Checkpointing, Shadow Paging, and Distributed Databases.
