# CSE 3103: Operating Systems Concepts

- **Week 1:** Introduction to Operating Systems, System Calls, Dual-mode execution (User mode vs Kernel mode), Process Architecture.
- **Week 2:** Process Control Block (PCB), Process States, Context Switching, Inter-Process Communication (IPC) via Shared Memory and Message Passing.
- **Week 3:** Threads & Concurrency: Multithreading models (User vs Kernel threads), Thread libraries (Pthreads), Synchronization problems.
- **Week 4:** CPU Scheduling Algorithms: First-Come First-Served (FCFS), Shortest Job First (SJF), Round Robin (RR), Priority Scheduling, Multi-level Feedback Queues.
- **Week 5:** Process Synchronization: Critical Section Problem, Peterson's Solution, Hardware Synchronization primitives, Semaphores, and Mutexes.
- **Week 6:** Classic Synchronization Problems: Bounded Buffer (Producer-Consumer), Readers-Writers, Dining Philosophers.
- **Week 7:** Deadlocks: Necessary Conditions, Resource Allocation Graphs, Deadlock Prevention, Avoidance (Banker's Algorithm), and Detection & Recovery.
- **Week 8:** Main Memory Management: Contiguous Memory Allocation, Paging, Page Tables, Segmentation, Internal & External Fragmentation.
- **Week 9:** Virtual Memory: Demand Paging, Page Fault Handling, Page Replacement Algorithms (FIFO, Optimal, LRU, Clock algorithm), Thrashing.
- **Week 10:** Mass-Storage Systems: Disk Structure, Disk Scheduling Algorithms (FCFS, SSTF, SCAN, C-SCAN, LOOK), RAID architectures.
- **Week 11:** File System Interface & Implementation: File concepts, Access Methods, Directory structures, Allocation methods (Contiguous, Linked, Indexed), Inodes.
- **Week 12:** OS Security & Virtualization: Access Control Lists, Hypervisors (Type-1 vs Type-2), Containerization (Docker concepts), Microkernel design.
