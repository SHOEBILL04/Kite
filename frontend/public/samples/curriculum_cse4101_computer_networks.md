# CSE 4101: Computer Networks & Protocol Design

- **Week 1:** Computer Networks Introduction, Network Topologies, Packet Switching vs Circuit Switching, OSI 7-Layer Reference Model vs TCP/IP Protocol Suite.
- **Week 2:** Application Layer I: HTTP/1.1 vs HTTP/2 vs HTTP/3, Web Caching, Domain Name System (DNS), Email Protocols (SMTP, POP3, IMAP).
- **Week 3:** Application Layer II: Peer-to-Peer Architecture, Socket Programming (TCP Sockets, UDP Sockets), Client-Server Applications.
- **Week 4:** Transport Layer I: Multiplexing & Demultiplexing, Connectionless Transport (UDP), Checksums, Reliable Data Transfer Principles.
- **Week 5:** Transport Layer II: Transmission Control Protocol (TCP), 3-Way Handshake, Flow Control (Sliding Window), Congestion Control (Tahoe, Reno, Cubic).
- **Week 6:** Network Layer I (Data Plane): Router Architecture, IP Addressing (IPv4, CIDR Subnetting, IPv6 Transition), NAT (Network Address Translation).
- **Week 7:** Network Layer II (Control Plane): Routing Algorithms, Distance Vector Routing (RIP), Link State Routing (OSPF), BGP (Border Gateway Protocol).
- **Week 8:** Link Layer & LANs: Error Detection & Correction (Parity, Checksum, CRC), Multiple Access Protocols (CSMA/CD, CSMA/CA), Ethernet switches.
- **Week 9:** Wireless & Mobile Networks: IEEE 802.11 Wi-Fi, Cellular Networks (4G LTE, 5G NR architecture), Mobility Management.
- **Week 10:** Network Security: Symmetric & Asymmetric Encryption (AES, RSA), TLS/SSL Handshake, Public Key Infrastructure (PKI), Firewalls & IDS.
- **Week 11:** Software Defined Networking (SDN): OpenFlow Protocol, Control Plane Decoupling, Network Function Virtualization (NFV).
- **Week 12:** Performance Evaluation & Measurement: Packet Loss, Round Trip Time (RTT), Throughput, Latency, Wireshark Packet Inspection labs.
